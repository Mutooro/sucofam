Option 1: How to Setup in Outlook (Perfect & Bulletproof)

Outlook has a dedicated signature folder. Saving this file directly there ensures 100% accurate formatting without copy-pasting code.

  1. Press the Windows Key + R on your keyboard to open the Run window.
  2. Type %appdata%\Microsoft\Signatures and press Enter.
  3. A folder will open. Copy this HTML file (maate_signature.html) and paste it inside that folder.
  4. Rename the file to Maate Coroneri.htm (make sure to change the extension from .html to .htm).
  5. Restart Outlook. When you draft a new email, select the "Maate Coroneri" signature from the signature dropdown menu!

Option 2: How to Setup in eM Client (Import HTML)

  1. Open eM Client and go to Menu > Settings > Mail > Templates & Signatures.
  2. Click the Signatures button, then click Add to create a new signature.
  3. Type a name for the signature (e.g., "Maate SUCOFAM").
  4. Right-click in the editor text field, select Insert HTML or click the HTML button on the formatting toolbar, and paste the code or load the file directly.
  5. Save and set it as your default signature.
